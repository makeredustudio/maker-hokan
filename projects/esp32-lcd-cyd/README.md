# ESP32 LCD CYD（Cheap Yellow Display）

ESP32-2432S028R 等 Cheap Yellow Display 教學、巴士天氣屏範例、自我學習簡報，以及社群／Larry 創作分享。

## 結構

```
examples/          Arduino 範例（BUS、LCD test）
self-learning/     自我學習簡報（唔含大檔影片，見 SKIPPED.md）
other/             活動導讀、Threads／FB 分享、連結
creations/
  larry/           Larry 作品：Dino Run、CPT 注意力、靜觀呼吸機
  cyd-fb-ideas/    由 CYD Facebook 靈感 AI 補完嘅 14 個示範專案
libraries.zip      Arduino libraries 打包（約 99 MB；推 GitHub 時建議用 Git LFS）
```

## CYD FB Ideas（01–14）

GPS 超速警告、Home Assistant 控制板、WiFi 像素時鐘、LVGL 入門、飛行追蹤、電子琴、CCTV 監察、溫度時鐘 SD、BLE HID、翻頁時鐘、發電機儀表板、藍牙雷達、OctoPrint 監察、無人機偵測示範。

每個子資料夾多數有 `.ino`、`.zip`、`README.md`／說明、FB 截圖。
