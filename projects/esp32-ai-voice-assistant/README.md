# ESP32 AI 語音助手（OpenRouter／唔使 Muse）

手把手教學：用 ESP32 做廣東話 AI 語音助手，經 OpenRouter 接 LLM，唔使 Muse。

## 內容

| 檔案 | 說明 |
|------|------|
| `ESP32_Cantonese_AI_Voice_Assistant_Beginner.pptx` | 初學者版簡報 |
| `ESP32_AI_Voice_Assistant_v2_Gmail_Calendar.pptx` | v2：含 Gmail + Calendar |
| `google_readonly.py` | Google API 唯讀輔助腳本 |
| `google_readonly_README.md` | 腳本說明 |
| `pcba/` | ESP32-S3 AI 聊天機械人 PCBA（BOM、原理圖、KiCad、方塊圖、設計說明） |

## PCBA 版本

- **v1**：語音 + 機器視覺（s3cam）
- **v2**：加遊戲按鍵
- **v3**：類比搖桿

每個版本有 schematic PDF、JLCPCB BOM CSV、KiCad5/6 for 立創 EDA zip、設計說明 docx。
