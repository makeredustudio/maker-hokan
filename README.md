# Maker 補完計劃 / Maker Complement Plan

靈感取自《新世紀福音戰士》的「人類補完計劃」。  
Name inspired by *Neon Genesis Evangelion*'s "Human Instrumentality Project".

由 **學造工作室（Maker Education Studio Limited）** 為「香港 Maker 創客討論區」Facebook 群組及工作室成員而設。

Maintained by **學造工作室 / Maker Education Studio** for the Hong Kong Maker community and studio members.

- 網站 Website: [https://makeredu.studio](https://makeredu.studio)
- GitHub: [https://github.com/makeredustudio](https://github.com/makeredustudio)
- Drive 公開來源：Maker 補完計劃 →「公開」資料夾（本 repo 只同步公開內容，唔包括「私人」）

---

## 計劃目的 / Purpose

| 中文 | English |
|------|---------|
| **資源共享**：共享設計與創作成果 | Share designs and maker projects |
| **善用 AI**：用 AI Agent 協助生成所需資料 | Use AI agents to help generate materials |
| **參與方式**：歡迎建立個人資料夾並上載作品 | Add your own project folder and upload your work |
